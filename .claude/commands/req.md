# Requirements Analysis

Analyze the following requirement and break it down into actionable items.

## Input

$ARGUMENTS

## Tasks

1. **Understand the Requirement**
   - Identify the user need
   - Define the scope
   - Note any constraints

2. **Create User Stories**
   - Format: "As a [user], I want [feature] so that [benefit]"
   - Include acceptance criteria

3. **Technical Breakdown**
   - List technical tasks
   - Identify dependencies
   - Note potential risks

4. **Output Structure**

Provide output in this format:

```markdown
## Summary
[Brief description of the feature]

## User Stories
- [ ] Story 1 with acceptance criteria
- [ ] Story 2 with acceptance criteria

## Technical Tasks
1. Task with complexity (S/M/L)
2. Task with dependencies

## Risks & Considerations
- Risk with mitigation approach

## Questions
- Any clarifications needed
```
